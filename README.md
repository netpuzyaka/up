# Up Bot Dashboard

Панель мониторинга для бота «Up Bot». Сайт статический: он читает файл `data/stats.json`, который бот автоматически коммитит в этот репозиторий через GitHub API.

## Как развернуть на Vercel

1. Залейте этот репозиторий на GitHub (он должен быть **публичным**, иначе сайт не сможет прочитать `stats.json`).
2. Зайдите на [vercel.com](https://vercel.com) → **Add New Project** → импортируйте репозиторий `netpuzyaka/up`.
3. Framework Preset: **Other**, остальное по умолчанию → **Deploy**.
4. Готово — дашборд будет доступен по ссылке вида `https://up-xxxx.vercel.app`.

## Как бот отправляет статистику

1. Создайте GitHub Personal Access Token (classic) с правами **repo**:
   https://github.com/settings/tokens
2. Сохраните токен в файл `github_token.txt` рядом с exe бота (одна строка — токен).
3. После каждой «тик»-отправки бот обновляет `data/stats.json` в репозитории.
4. Дашборд обновляется автоматически каждые 60 секунд.

## Что показывает панель

- Сервер: название, ID, ссылка-приглашение
- Темы (каналы): имя, ID, успешные/неуспешные отправки, последний результат
- Аккаунты Discord: имя, статус, счётчики, последний канал и время
- Журнал отправок: время, аккаунт, канал, результат, ошибка
