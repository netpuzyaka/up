# Up Bot Dashboard

Панель мониторинга и управления для бота «Up Bot».

## Как развернуть на Vercel

1. Репозиторий должен быть **публичным**.
2. На [vercel.com](https://vercel.com): **Add New Project** → импорт `netpuzyaka/up` → Framework Preset: **Other** → **Deploy**.
3. В настройках проекта Vercel добавьте переменную окружения:
   - `GITHUB_TOKEN` — GitHub Personal Access Token (classic) с правом **repo** (https://github.com/settings/tokens)
4. Сделайте **Redeploy** (после добавления переменной).
5. Адрес сайта вида `https://up-xxxx.vercel.app` — укажите его в панели в поле «Адрес API сайта» (или в settings.json как `apiUrl`).

## API сайта

- `GET /api/stats` — все клиенты со статистикой (для панели)
- `POST /api/stats` — бот отправляет `{ clientId, name, stats? }`; сервер сохраняет статистику в репозиторий (`data/clients/{id}/stats.json`) и обновляет реестр клиентов (`data/clients.json`)

Когда `apiUrl` задан, бот шлёт данные напрямую на сайт — `github_token.txt` на ПК клиента не нужен (токен хранится только на Vercel).

## Панель

- Обзор: сводка, круговая диаграмма успех/ошибки, распределение по темам, клиенты (онлайн/офлайн), каналы, аккаунты, журнал
- Управление: настройки (каналы, текст, интервал, инвайт, тип токена, адрес API), Discord-токены (загрузка файлом / скачивание), GitHub-токен (запасной вариант), остановка бота

Панель управляет локальным ботом через `http://127.0.0.1:8787` (работает, когда бот запущен на том же ПК).
